# AeroVault-first assembly animation
Source: active AeroNode Flight Case, visible NOVA cylindrical-pair configuration. Exported228 visible mesh/BRep body instances recursively, retaining installed transforms and source materials where available. Fusion source archive preserved and Fusion geometry unmodified.

Animation:18 seconds,432 frames at24fps,1920x1080. Smooth360-degree rotation. AeroVault close-up first; thermal bottom/perimeter and capsule body assemble, thermal top and metal lid close; camera widens, base/saddles/IMU/main PCB/batteries/cooler/transparent case/logo/screws assemble in sequence. Timeline markers identify stages. Assembly translation paths are presentation choreography, not validated manufacturing instructions. Current capsule and thermal geometry are unverified concepts and imply no crash/thermal qualification. Unknown fasteners/feedthroughs not invented.

Blender scene and H264 MP4 intended deliverables. All Blender assets use locally embedded meshes/materials; no external texture dependencies. Fusion linked board dependencies may remain in source archive. Animation may expose existing fit limitations in source CAD, which was not redesigned for this task.

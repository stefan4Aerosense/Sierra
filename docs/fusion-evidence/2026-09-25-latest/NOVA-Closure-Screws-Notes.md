# NOVA closure screws
Added four modeled M2.5 x 8 screws with satin titanium appearance at the measured corner axes, inserted from underneath. Heads bear on the base underside and project 1.5 mm. Each passes through a 2.7 mm clearance hole, engages the existing 2.1 mm pilot for 6 mm and leaves 2 mm tip clearance. Verified solid bodies and zero screw/base interference.

Concept fasteners only: pilot tapping versus threaded inserts requires engineering review. PCB through-bores, battery saddle attachment and AeroVault capsule attachment remain unfinished; this update does not establish crash protection. IMU retains its existing edge clips.

# One-piece TPU cushion / integral sensor sleeve
Current curved cushion document updated. Original rigid hardware hidden and preserved; Before.f3d captures previous version.

Single connected TPU structural solid includes cushion, sleeve, optical mask and two compliant keeper lips. Optical windows and sensor remain separate components; ordinary TPU must not cover optical paths. Insertion from flat underside: disconnect ribbon, spread soft keeper lips, push board into top seat, release lips behind board edge, reconnect ribbon. Finger reliefs permit spreading the sleeve. No separate rigid carrier, plate or screws in active design.

Cavity 15.6 x 21 mm for provisional board 15 x 20.4 mm, 0.3 mm clearance per side. Keeper lips 0.7 mm thick with intentional edge overlap. This fit is a starting assumption, not verified for a TPU grade. Test coupon, PCB component clearances, optical sealing, strain relief and comfortable compressed fit required. Elastic retention has not been simulated. Sensor geometry provisional. Print orientation/support removal for long narrow cavity requires slicer review.
